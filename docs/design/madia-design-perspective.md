# 마디아의 디자인 판단 관점과 활용법

이 문서는 Madia Designer의 공개 자료에서 확인한 관점을 나중의 디자인 제작·리디자인·리뷰에 재사용하기 위한 참고 자료다. UI·웹 화면과 정보 전달 중심 그래픽을 주 대상으로 한다.

핵심은 **사용자가 해야 할 일과 먼저 알아야 할 내용을 정하고, 요소 사이의 강약과 정보 관계를 그 목적에 맞게 만드는 것**으로 정리할 수 있다. 이는 여러 공개 설명을 묶은 분석자의 해석이며, 제작자가 자신의 사고 전체를 이렇게 정의했다는 뜻은 아니다.

## 읽을 때 알아둘 근거 범위

2026-10-15 기준 공개 영상 1,352개의 목록을 수집했다. 공식 설명·챕터·공개 전사 일부 중 장편 20개와 쇼츠 30개를 근거 지도에 선별했고, 그중 쇼츠 1개는 구체적 기준이 없어 판단 근거에서 제외했다. 전체 영상을 시청하거나 자막 전문을 분석한 것은 아니다.

아래에서는 채널의 **공식 설명에서 확인한 관점**과, 이를 gx에 사용하기 위해 만든 **적용 방법**을 구분한다. 실제 시선 추적, 과업 성공률, 전환 개선이 검증됐다는 의미로 읽지 않는다. 상세한 수집 범위와 실패 항목은 [조사 기록](../research/2026-10-15-madia-design-judgment.md), 출처별 확인 수준은 [근거 지도](../../skills/gx-design/references/madia-evidence.md)에 있다.

## 1. 화면을 그림보다 과업과 상태로 본다

공식 설명에서는 여행 편의 앱의 기획 부재와 상태·예외 누락을 지적하고, AI 채팅과 주문서에서는 입력 변화·화자 구분·누락 정보·금액 관계를 다룬다. 정상 상태의 보기 좋은 화면만으로 설계가 끝났다고 판단하기 어렵다는 관점이다. [여행 앱 사례](https://www.youtube.com/watch?v=kvtDeVtTzyM), [AI 채팅 사례](https://www.youtube.com/watch?v=IPRDf2caww8), [주문서 사례](https://www.youtube.com/watch?v=IcWw0O4SorU)

**적용:** 먼저 사용자가 이해·입력·선택·확인할 일을 적는다. 그 과업에 필요한 필수 정보와 상태를 고른다. 예를 들어 채팅이면 긴 답변·입력 중 변화·오류·키보드 등장, 주문서면 배송·상품·혜택·결제·합계의 관계를 확인한다. 제공되지 않은 정책과 가격 산식은 임의로 만들지 않는다.

## 2. 강조는 주변 요소와의 관계에서 판단한다

브랜드색을 모든 행동에 강하게 쓰면 중요도가 흐려질 수 있고, 배경만 강하면 내부의 핵심 내용은 덜 읽힐 수 있다고 설명한다. 강조할 대상을 먼저 정하고 강한 것과 약한 것을 함께 만드는 관점이다. [컬러 계층](https://www.youtube.com/watch?v=SdWN34yCMNs), [배경과 핵심 내용의 경쟁](https://www.youtube.com/watch?v=kIsFItgncCc)

**적용:** 제목·이미지·색 면·버튼 중 먼저 보이는 대상을 확인하고, 의도한 우선순위와 비교한다. 크기뿐 아니라 면적·굵기·채도·명도 대비·주변 여백을 함께 본다. 핵심을 더 키우는 방법과 주변을 낮추는 방법을 비교한다.

## 3. 글자를 꾸밈보다 읽히는 계층으로 본다

UI 타이포의 역할을 브랜드 이름의 조형과 구분하며, 사용자가 읽기 쉬운 계층을 만드는 데 초점을 둔다. [UI 타이포의 역할](https://www.youtube.com/watch?v=y-UngjyBhQg), [인접 제목의 상대적 위계](https://www.youtube.com/watch?v=XTcZlHh8K4U)

**적용:** 제목·본문·보조 정보·행동의 역할부터 나눈다. 실제 문장과 긴 콘텐츠로 크기·굵기·줄바꿈·행간·정렬을 확인한다. 모든 글자를 동시에 키우거나 굵게 하면 역할 구분이 다시 약해질 수 있다. 한 영상의 예시 크기를 모든 제품의 규격으로 고정하지 않는다.

## 4. 여백과 그룹을 정보의 소속을 설명하는 수단으로 본다

흩어진 정보는 읽기 어렵고, 카드 안의 여백도 내용이 조각나 보이게 할 수 있다고 설명한다. 한편 세부까지 모두 무거운 덩어리로 만들면 가볍게 읽을 영역이 줄어든다는 반대 조건도 제시한다. [정보 그룹](https://www.youtube.com/watch?v=AfO-B6FYkeQ), [카드의 간격](https://www.youtube.com/watch?v=TNjGSE9992A), [세부 덩어리의 무게](https://www.youtube.com/watch?v=SXiQPGhTP5M)

**적용:** 상품과 가격, 제목과 설명, 질문과 답변처럼 함께 이해해야 할 관계를 먼저 찾는다. 내부 간격과 그룹 사이 간격, 정렬·배경·테두리가 그 관계를 전달하는지 본다. 카드·구분선을 무조건 추가하거나 없애지 않는다.

## 5. 크고 시원한 구성을 사이트 성격에 따라 선택한다

과감한 제목과 여백을 시도하도록 권하면서도, 종합몰의 큰 배너가 상품을 첫 화면 아래로 밀 수 있다는 점과 사이트 성격에 따라 비중을 판단해야 한다는 조건을 설명한다. [과감한 크기 시도](https://www.youtube.com/watch?v=og2SNAe7H5o), [배너 크기의 조건](https://www.youtube.com/watch?v=1UUe_qB8t4M), [볼륨감의 조건](https://www.youtube.com/watch?v=CkR_oavrntQ)

**적용:** 이미지 감상·브랜드 이야기·상품 비교·운영 작업 중 무엇이 중요한지에 따라 밀도를 정한다. 큰 히어로와 여백은 전달·몰입을 도울 때 사용하고, 상품 탐색이나 반복 비교를 밀어내면 비중을 조정한다. 목적 없이 해상도를 채우는 빈 공간도 경계한다. [목적 없는 빈 공간](https://www.youtube.com/watch?v=dT-OarWW2Wo)

## 6. 이미지를 크기뿐 아니라 색과 시각적 비중으로 본다

이미지마다 컬러와 부피감이 있어 모두 강하면 균형이 무너질 수 있다고 설명한다. 이미지를 강조하려는 목적에서는 다른 요소가 핵심 피사체를 가리는지도 문제로 본다. [이미지의 균형](https://www.youtube.com/watch?v=CoTQ17DcJZI), [이미지 가림](https://www.youtube.com/watch?v=SrFRKdTseuI)

**적용:** 이미지의 비율·크롭·피사체 노출·채도·대비·복잡도를 같이 판단한다. 이미지 중심 코너라면 주변 장식을 늘리는 방법과 콘텐츠 자체를 키우는 방법을 비교한다. 사진 여러 장을 같은 크기로 맞추는 것만으로 균형이 완성됐다고 보지 않는다.

## 7. 효과를 추가하기 전에 전달에 기여하는지 본다

글래스와 그래픽 효과의 남용, 타이포 기본기, 정보 인지의 질서를 다루는 공식 설명에서 장식보다 읽힘과 사용 맥락을 강조한다. [글래스 UI 컨펌](https://www.youtube.com/watch?v=VPJDJkfkAe8), [패션 매거진 컨펌](https://www.youtube.com/watch?v=Ah5mgWM8Cuc)

**적용:** 효과가 콘텐츠 이해·상태 피드백·브랜드 표현에 어떤 역할을 하는지 설명한다. 중복·경쟁·노이즈를 만드는 표현을 줄이되, 선택 상태·경고·소속·필수 안내를 나타내는 단서는 보존한다. 미니멀한 외형 자체를 목표로 삼지 않는다.

## 8. 벤치마킹과 시스템을 선택 이유와 사용 조건까지 포함해 본다

유명 서비스 참고의 함정, 카피를 넘어 기획으로 접근하는 태도, 관리 가능한 케이스와 컴포넌트 관리의 중요성을 다룬다. [웹 설계와 레퍼런스](https://www.youtube.com/watch?v=L8XzzZOze7w), [방향과 시스템 관리](https://www.youtube.com/watch?v=WU2Pp4uvmus), [가이드와 케이스 관리](https://www.youtube.com/watch?v=0U0IaLxfJUI)

**적용:** 레퍼런스의 사용자·과업·콘텐츠 양·장치가 현재 상황과 맞는지 비교한다. 같은 역할은 기존 토큰·컴포넌트를 재사용하고, 필요한 상태·정보량 차이에는 변형을 허용한다. 겉모습이 비슷하다는 이유로 적합성을 확정하지 않는다.

## 실전에서 이렇게 구분한다

아래는 관점을 적용하기 위해 구성한 예시이며, 마디아의 실제 컨펌 장면을 재현한 것이 아니다.

| 상황 | 우선 판단 | 변경 방향과 유지 조건 |
|---|---|---|
| 환불 마감 건을 찾는 운영 대시보드 | 홍보·일반 통계가 마감 정보보다 강하게 보이는가 | 마감 요약과 해당 주문의 연결을 강화. 브랜드색·메뉴·금액·정책 보존 |
| 전문 바이어의 상품 비교 화면 | 여러 상품의 재고·단가·수량을 같은 기준으로 비교할 수 있는가 | 고밀도 표와 일관된 항목 순서 사용. 필요한 반복 구조와 실제 데이터 보존 |
| 소재감을 보여주는 가구 캠페인 | 큰 사진과 이야기의 흐름이 승인 목적을 전달하는가 | 큰 이미지·여백 유지. 피사체 가림·크롭·글자 읽힘·문의 경로 확인 |
| AI 채팅 화면 | 화자와 답변, 보조 정보, 입력 상태가 구분되는가 | 정렬·묶음·상태 단서를 일관되게 사용. 장식 축소 중 화자·오류 정보를 잃지 않기 |

## 리뷰할 때 꺼내 쓸 질문

1. 이 화면에서 사용자가 하려는 일과 먼저 알아야 할 것은 무엇인가?
2. 실제 화면에서 먼저 눈에 들어오는 대상이 그 우선순위와 맞는가?
3. 모든 요소가 강하거나, 모두 비슷해서 핵심이 흐려지지는 않는가?
4. 함께 읽을 정보가 함께 보이고, 다른 역할은 구분되는가?
5. 글자·색·이미지·여백 각각의 선택 이유가 콘텐츠와 연결되는가?
6. 과감함과 밀도가 제품 성격·장치·과업에 맞는가?
7. 입력·오류·긴 콘텐츠 등 필요한 상태에서도 의미와 조작을 유지하는가?
8. 변경 뒤 같은 조건에서 원래 문제와 새로 생긴 문제를 확인했는가?

## 재사용용 작업 요청

다음 형식은 gx가 구성한 적용 방법이다. 제작자의 실제 작업 순서를 인용한 것이 아니다.

```text
목적과 사용자의 주 과업을 먼저 정리해 주세요.
제공된 화면에서 먼저 보이는 정보·행동과 의도한 순서를 비교하고,
시선 경쟁, 정보 묶음, 읽힘, 필요한 상태를 근거로 판단해 주세요.

진단: 위치·상태 / 관찰 / 영향 가설 / 변경 방향 / 확인 방법
수정: 변경 ID → before → after → 진단 ID 또는 승인 목표 ID와 연결한 근거
보존: 브랜드·필수 정보·정책·의미 있는 상태와 승인된 유지 자산
검수: 같은 콘텐츠·화면 크기·상태에서 원래 문제와 회귀 확인

확인하지 못한 것은 한계로 남기고, 시각적 정돈과 실측 성과를 구분해 주세요.
```

## 적용하면서 피할 단순화

| 단순화 | 함께 보존할 조건 |
|---|---|
| 모든 화면의 제목·배너를 크게 만들기 | 첫 화면의 필수 정보, 상품 노출, 작업 밀도와 스크롤 부담 |
| 여백을 많이 만들면 품질이 좋아진다고 보기 | 의미 있는 묶음·분리·읽기와 정보 밀도 |
| 카드·색·그림자를 모두 제거하기 | 정보 소속, 비교 단위, 선택·경고·피드백, 브랜드 표현 |
| 익숙한 서비스처럼 보이면 좋은 UX라고 보기 | 현재 사용자·과업·콘텐츠·정책과 맞는 이유 |
| 예시 픽셀값·회색을 모든 제품에 고정하기 | 실제 배경·언어·뷰포트·제품 시스템과 접근성 조건 |

접근성 수치는 별도의 공식 기준으로 확인한다. [W3C 대비 해설](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)과 [타깃 크기 해설](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)을 참고하고, 측정하지 않은 대비나 조작성은 통과로 표시하지 않는다.

## gx에서의 사용 위치

실행용 지침은 [DESIGN-JUDGMENT.md](../../skills/gx-design/DESIGN-JUDGMENT.md)에 있다. 신규 제작의 전략·제작, 리디자인의 진단·전략·수정, 자체 검수와 최종 검수가 같은 판단 계약을 참조한다. 이 문서는 사람이 관점을 이해하고 재사용하기 위한 해설이다.

새 자료를 추가할 때에는 공식 설명·챕터·발언·본편 화면의 확인 범위를 구분하고, 같은 시안의 전후편·쇼츠 재편집을 독립 사례로 중복 계산하지 않는다. 새로운 반례가 나오면 적용 조건을 함께 갱신한다.
