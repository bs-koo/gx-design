이 사례에서 바뀐 점

조회 조건과 진행 목록을
밝은 화면 안에 정리합니다.

밝은 바탕과 구분된 영역
흰 바탕에 조회 조건을 연한 배경으로 묶고, 진행 목록을 그 아래에 배치했습니다.
정돈된 목록 정보
신청일·접수번호·건축물명 등의 정보를 열로 정렬하고, 각 신청의 진행 단계를 배지로 표시했습니다.

인증조회 화면 한 건의 개선 사례이며, 모든 프로젝트의 품질이나 사용성 향상을 보장하는 성과 자료는 아닙니다.

필요한 디자인 업무에서
시작하세요.

새로운 방향을 기획할 때도, 기존 결과물을 다듬을 때도.
목표와 기존 자료를 바탕으로 필요한 작업과 결과물 형식을 정합니다.

  • 브랜드

    브랜드의 방향과 시각 언어를 정할 때

    결과물 예시브랜드 콘셉트, 컬러·타이포그래피, 적용 가이드

  • 그래픽

    캠페인의 메시지를 시각물로 만들 때

    결과물 예시키비주얼, 배너·포스터, 제작 명세

  • UX/UI

    화면을 설계하거나 사용 흐름을 개선할 때

    결과물 예시화면 구조, 프로토타입, 개선·검수 보고

  • 영상

    영상의 구성과 장면별 연출을 기획할 때

    결과물 예시스토리보드, 장면·모션 명세, 제작 프롬프트

요청한 형식과 현재 작업 환경에 맞춰 제작합니다. 문서·프롬프트와 실제 이미지·영상·실행 화면의 제작 여부를 구분해 안내합니다.

새로 만들기와 기존 개선.
상황에 맞게 요청하세요.

대상, 목표, 유지할 조건을 알려주세요. 기존 자료에서 확인되는 내용과 이미 정한 방향은 이어서 사용합니다.

새로운 디자인을 만들 때

아이디어를 구체화하고, 필요한 근거와 방향을 정해 결과물로 만듭니다.

/gx-design:gx-design
Codex
$gx-design
이렇게 요청하세요협업툴 소개 페이지를 만들어줘. 대상은 도입을 검토하는 IT 팀장이고, 목표는 도입 문의야. 기존 브랜드 가이드를 유지하고 모바일도 함께 설계해줘.

이어지는 작업 필요한 의도 확인 → 방향 설정 → 제작 → 최종 검수

기존 디자인을 개선할 때

현재 결과물에서 문제를 확인하고, 유지할 자산과 합의한 수정 범위 안에서 개선합니다.

Claude Code
/gx-design:gx-redesign
Codex
$gx-redesign
이렇게 요청하세요이 인증조회 화면을 개선해줘. 밝은 바탕에서 조회 조건과 진행 목록이 구분되도록 정리하고 싶어. 기존 조회 기능과 신청 정보는 유지해줘.

이어지는 작업 기존 화면 진단 → 수정 범위 확인 → 개선 → 변경 전후 검수

수정하지 않고 점검 결과만 받을 수도 있나요?

네. 개선 명령에 “점검만. 고치지 말고 문제를 정리해줘”라고 적어주세요. 화면 URL이나 파일, 확인할 기기와 사용 흐름을 함께 알려주면 해당 범위의 진단 보고로 마칩니다. 실제 조작 검증은 사용 가능한 브라우저 실행 환경에서 진행하며, 확인하지 못한 부분은 별도로 표시합니다.

설치·유지보수 안내

Claude Code에 설치

Claude Code에서 차례로 실행

/plugin marketplace add bs-koo/gx-design
/plugin install gx-design@gx-design

설치 후 Claude Code를 재시작하고,
/gx-design:gx-design 또는 /gx-design:gx-redesign 뒤에 요청을 적으세요.

Codex에 설치

터미널에서 차례로 실행

codex plugin marketplace add bs-koo/gx-design
codex plugin add gx-design@gx-design

설치 후 새 Codex 대화에서
$gx-design 또는 $gx-redesign 뒤에 요청을 적으세요.

복사가 되지 않으면 위 명령을 직접 선택해 복사하세요. 자동 복사는 HTTPS와 클립보드 권한이 필요할 수 있습니다.
