## gx가 추가한 운영 계약

`관찰 → 과업 영향 가설 → 변경 → 유지 조건 → 같은 조건의 재확인`이라는 출력 형식, 진단 행 연결, 모드별 적용과 보고 계약은 위 자료를 gx에 적용하기 위해 설계한 것이다. 제작자의 발언이나 실험으로 검증된 표준 절차로 인용하지 않는다.

접근성 수치는 영상의 예시와 별도로 공식 기준을 확인한다. [WCAG 대비 해설](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)은 실제 전경·배경 대비를, [타깃 크기 해설](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)은 크기·간격·예외 조건을 다룬다. 한 색상이나 버튼 크기를 모든 상황의 보증값으로 사용하지 않는다.
