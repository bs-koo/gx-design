# 호스트 호환 실행 규칙

## 질문·선택

실제 제공된 구조적 입력 도구가 있으면 그 도구의 문항 수, 필수 선택 방식, 허용되는 응답 형식에 맞춰 질문한다. 한 라운드의 질문은 가능한 한 함께 묻는다. 구조적 질문 도구가 없거나 그 도구의 문항·옵션·선택 방식 제한으로 모든 경로 선택지를 그대로 제시할 수 없으면, 모든 선택지를 빠짐없이 대화에 제시해 묻고 답변을 기다린다. 도구 제한에 맞추려고 경로를 생략하거나 합치지 않는다. 옵션별 시각 미리보기를 제공할 수 없으면 선택지를 텍스트로 적는다. 사용자가 이미 결정을 명시했으면 같은 질문을 반복하지 않는다.

## 답변 게이트

브리프 승인, 전략 선택, 실물 제작 경로처럼 사용자 결정에 따라 결과가 달라지는 단계는 답변을 받은 뒤 진행한다. 이는 확인·선택으로 표현한다. 이미 받은 승인·선택은 유지한다. 결정 전까지 파일 조사와 문서 정리 등 독립 작업은 진행한다. 사용자가 명시적으로 진행을 요청하면 미해결 항목은 [가정]으로 기록한다.

## 위임

사용자 또는 프로젝트 지시가 위임을 허용하고 실제 하위 작업자 도구가 있으면 역할, 입력 11항목, 산출 경로, 완료 기준을 명시해 위임한다. 특정 작업자 이름·모델·방식을 자동으로 주입하거나 전제하지 않는다. 위임 도구가 없으면 주 작업자가 해당 방법으로 수행하고 같은 산출물 계약을 따른다.

## 도구 가용성

파일 탐색, 웹 조사, 이미지 열기, 렌더링은 현재 환경에서 실제로 쓸 수 있는 도구를 확인한 뒤 수행한다. 특정 도구가 없으면 확인하지 못한 사실과 만들지 못한 산출물을 명시하고 가능한 문서·프로젝트 경로를 따른다. 외부 서비스 이용은 사용자 지시와 실행 환경의 권한을 따른다.
